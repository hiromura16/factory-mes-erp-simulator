# コード読解ガイド

## 入口とデータの流れ

1. `app.py` が `factorylib.create_app` に種別とアダプターを渡し、設定保存と実行履歴を初期化します。importにも副作用があるため、読解だけの目的で実行しません。
2. `config.py` がv2入力の型と組合せを検証し、`helptext.py` が表示用スキーマへ日本語の意味を付けます。モデルの成立は接続先への疎通成功とは別です。
3. `factorylib.py` がプレビュー用に代表位置を選び、アプリごとの見本を返します。実行時の停止や進捗は `Runtime` が管理します。
4. アダプターが方式別のI/Oを担い、`storage.py` が接続の暗号化履歴とプリセットを管理します。受付・書込み・配送確認・下流反映は別の状態です。

## 読む際の境界

- 生成キーと項目別乱数は再現性のために固定します。異常ルールの順序や参照元の定義順には意味があります。
- 既定モードや命名・契約・認証情報の取扱いは説明追加では変更しません。
- API handlerとPydanticクラスは、docstringがOpenAPI/JSON Schemaに露出し得るためコメントで説明します。CLIの既存 `__doc__` も維持します。
- テストのスタブや一時保存先を、本番の接続や権限保証と混同しません。部分コミット・送信後の応答喪失・下流処理は各アダプターの説明を参照してください。

## ブラウザーと操作

`static/app.js` は画面状態、設定の読書き、プレビュー、実行状態の取得をまとめます。各関数と入れ子callbackの直前に入力・DOM/状態変更・失敗処理の意味を記しています。DOMの見た目の更新とAPI経由の実操作を分けて読んでください。

## SQL操作時の接続と対象テーブル

`static/app.js` の `sqlActionSnapshot()` が、画面に表示された接続先のIDと版、テーブル、操作、生成条件を控えます。`sqlDatabaseAction()` は確認前後に対象が変わっていないことを照合します。接続の版が変わった場合は再取得へ戻り、その操作のPOSTを送りません。

DDLの確認とテーブル作成は別操作です。更新・削除・upsertの確認画面は、生成条件で設定した行数を表示します。実際の変更は、実行履歴と対象DBで確認します。[画面の確認処理](tests/sql_actions.test.cjs)と[接続版の回帰テスト](tests/test_sql_action_snapshot.py)で、取消し、同じ接続IDの版変更、確認中のテーブル変更を追えます。

## スクリプトとテスト

`scripts/` は初期化や宣言プリセットの生成を行います。生成スクリプトを読むことと、接続先へ適用することは別です。`tests/` は個々の回帰目的を関数直前で説明しています。実接続するprotocol試験と、一時ファイル/SQLiteやスタブを使う試験を区別して実行してください。

## SQL固有の流れ

`db_connections.py` がDB方式と認証に応じた接続を組み立て、`database.py` が列・主キーを照合してバッチ反映します。更新・削除では主キー一致が必要です。後続バッチの失敗でも先行コミットは自動では戻りません。DDLの文字列生成と実際の表準備も別操作です。

## Compose宣言の読み方

`compose.yaml` には公開アドレス・ポート、資源上限、永続ボリューム、外部監視用ラベルを定義しています。環境変数の設定と既存ボリュームの扱いは[VMへのDocker Compose導入手順](docs/vm-compose.md)を参照してください。

## 生成器を追加する

設定モデルに名前と入力制約を追加します。`generation.py` では同じシードと位置から同じ値を返します。丸め・欠測・先行項目の参照をテストし、`helptext.py` の説明と契約を更新します。

## 出力方式を追加する

接続モデルに方式と秘密値の定義を追加し、アダプターに接続の確認と実行を実装します。再試行後も出力状態を追えること、エラーに資格情報が出ないこと、見本が外部I/Oを伴わないことを確認します。

## 組み込みヘルプを更新する

Markdownと設定モデルを編集したら `uv run --frozen --with markdown-it-py==4.0.0 python scripts/build_help.py` を実行します。`--check` は生成済みファイルとの一致を検証します。

## 共通コードを同期する

生成エンジン、ヘルプとHTTPの共通ファイルは8リポジトリで揃えます。1本を変更したら適用先にも反映し、`docs/shared-components.json` に各ファイルのSHA-256を記録します。 `uv run --frozen python scripts/check_shared.py ../他アプリの作業ディレクトリ` で同じ変更をまとめて照合できます。CIでもローカルの共通ファイルと記録を照合します。
